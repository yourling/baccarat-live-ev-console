# Dafabet/mstrom 真实下注验收指南

本指南用于让操作者验证当前实现已经正确连接到 Dafabet/mstrom。除最后一节外，所有步骤都不会调用平台的 `confirmBet`，不会提交真实下注。

## 验收边界

当前适配器只支持：

- 平台：Dafabet/mstrom。
- 市场：`bankerPair`（庄对）和 `playerPair`（闲对）。
- 页面：浏览器中恰好一个 Dafabet 百家樂弹窗。
- 目标：该弹窗的 iframe 中恰好一个 frame 持有目标桌台的 BetStore。

以下情况必须失败关闭，而不是尝试下注：

- 扩展未连接，或同时存在多个扩展连接。
- 未显式开启本次 WebSocket 会话的 live gate。
- 找到零个或多个 Dafabet 百家樂弹窗。
- 找到零个或多个目标桌台 BetStore。
- 桌号、局号、下注窗口、平台玩法状态、限额、余额或未确认筹码状态不一致。

## 生成验收包

在仓库根目录执行：

```powershell
npm run build
npm test
npm run package:desktop:win
```

验收程序位于 `apps/desktop/release`。解压版会在 `win-unpacked/resources/browser-extension` 附带浏览器扩展；使用 portable `.exe` 时，先启动程序并从相邻的解压版目录加载扩展，或直接从 `apps/browser-extension` 加载开发扩展。

## 不下注的环境验收

1. 在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载浏览器扩展目录。
2. 启动桌面中控台；它会在 `127.0.0.1:17890` 启动本地桥。
3. 使用你自己的合法账号登录并打开一个 Dafabet 百家樂弹窗。保持只打开一个匹配页面。
4. 在中控台中选择目标桌台，确认实时事件开始进入监控列表。
5. 在新靴开始时执行“确认新牌靴”。桌台必须显示 `physical-shoe` 基线、`已连接`，并在下注阶段显示“下注窗口”。
6. 将执行模式切换为“启用真实下注（仅 Dafabet）”，确认自动下注仍处于“已暂停”。此步骤只开启执行资格，不会发出 `betRequest`。
7. 再切回影子模式，确认没有新增真实回执或 reservation。

预期结果：

- 若页面、扩展和桥接都正确，桌台持续接收实时事件，模式可以在影子与 live 间切换。
- 若扩展未连接或有多个扩展连接，切换 live 必须显示错误，不能静默继续。
- 若牌靴、连接或下注窗口条件不满足，“执行单次实盘下注”按钮必须保持禁用。

## 操作者自行决定的最小真实验证

只有在你明确决定验证平台真实回执时才进行本节。此操作会使用真实资金。

1. 保持自动下注为“已暂停”。
2. 等待目标桌台处于 `physical-shoe`、`已连接`、下注窗口开放，且界面显示当前游戏平台局号。
3. 打开该桌的设置，进入“单次实盘验证”。
4. 选择市场和你认可的最小合法金额。
5. 点击“执行单次实盘下注”，逐字输入弹窗给出的确认文本。
6. 只观察一次回执，不要因为超时或未知状态自动重试。

回执解释：

- `ACCEPTED`：平台已确认本次下注；随后等待牌局结算。
- `REJECTED`：平台明确拒绝；不应再次自动提交。
- `UNKNOWN`：`confirmBet` 已可能到达平台，但本机未能证明结果；保留 reservation，先在平台历史中人工核对，再决定后续处理。

## 验收记录

请保存以下信息，且不要保存密码、cookie、令牌或完整网络包：

- 桌号、牌靴 ID、局号、市场、金额。
- 中控台显示的执行模式、连接状态、下注窗口状态和回执状态。
- 若失败，错误文本和发生时间。
- 若为 `UNKNOWN`，平台账单或下注历史中的人工核对结果。
